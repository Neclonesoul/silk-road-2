# Changelog

## [Unreleased]

- Production provisioning, live QA and release tag intentionally left to the deployment engineer.

## [2.0.0] — prepared 2026-08-22

- Rebuilt the JavaFX/LAN marketplace as a mobile-first SvelteKit Cloudflare application.
- Added real accounts, secure sessions, email verification and password recovery architecture.
- Added normalized categories, structured attributes and explicit listing lifecycle states.
- Added progressive seller flow, drafts, validated R2 image uploads, ordering and covers.
- Added public browse/search/filter/detail/seller/favourite experiences.
- Added D1-backed listing-centric messages with Durable Object/WebSocket coordination.
- Added notifications, reports, blocks, moderation audit trail and protected admin surfaces.
- Added semantic light/dark design tokens, responsive navigation, PWA, offline fallback, SEO and sharing metadata.
- Added D1 migrations, CI, deployment workflow, unit tests, Playwright journeys and production operations documentation.
