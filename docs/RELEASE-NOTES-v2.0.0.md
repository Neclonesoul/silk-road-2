# Silk Road 2.0 — release notes draft

Silk Road returns as a complete mobile-first public marketplace built for direct trade.

## Highlights

- Honest inventory-first Explore and search experience
- Real seller accounts, secure sessions, verification and password recovery
- Fast progressive listing flow with drafts and up to 12 R2-backed photos
- Flexible taxonomy without per-category application rewrites
- Favourites, seller profiles and explicit available/reserved/sold states
- Listing-centric realtime buyer–seller conversations
- Notifications, reporting, blocking, moderation audit trail and protected admin area
- Installable PWA, dark mode, accessibility, SEO and social sharing foundations
- Production Cloudflare provisioning, CI, testing and operator runbooks

Production content starts empty. No fake sellers, reviews, sales or realtime signals are included.
